Chandigarh University Academic Project Specifications & Formulation

Matching Algorithm Formulation (Section 5.2): Score = w₁ · BloodMatch + w₂ · (1 / Distance) + w₃ · Availability + w₄ · ResponseHistory

Weights adapt dynamically with urgency: Critical puts 45% weight on distance and 25% on availability.

Haversine Distance Formula (Section 5.2): d = 2R · arcsin( √( sin²(Δφ/2) + cos φ₁ · cos φ₂ · sin²(Δλ/2) ) )

R = 6371 km Earth radius. Exact spherical geodesic calculation across latitude & longitude.
